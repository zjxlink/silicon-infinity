## 实际行为和边界

记录器测试覆盖初始化、重复序号、相同值不同序号、序号回绕、暂停/恢复、清空确认、满八条后不覆盖、数据写入与计数提交之间的窗口、断线、故障、冷暖复位、精确快照及封装双实例独立性。删除实际记录指令或断开数据通路会失败，面板不制造预设结果。

验证隔离执行候选工程，保留工作台的草稿、已应用版本、RAM、时间和排队输入。参考原样通过与玩家修改后的通过分开显示。固定任务完成条件不被自定义时间线覆盖。

时间线沿用现有合同和严格校验，保留高级字段与同刻事件顺序；同时刻项目可分别选择。截止检查只是该时刻检查，保持采样不证明采样间连续成立。

浏览器测试运行于 Windows。窄屏和触摸由浏览器仿真；WebKit 是 Windows 测试引擎，不等同于实体 iOS Safari 验收。缓冲、存储、工程、验证和房间均有限额。本版没有 Worker 后台计算、通信适配器或跨设备个人存档同步。

网站访问范围不变。第二个真实账号的正式联合验收继续按用户决定延后；本地身份及本地 D1 不替代该项。

## 存储与异步操作

实际 IndexedDB 验证了两个窗口同时保存、事务取消、失败原子性、完整现场恢复、旧库显式迁入且原文保持、离线保存及新环境文件导入。初始 SecurityError 可见回退，VersionError 与损坏拒绝切换空库；缺少 Web Locks 的回退仅提供读取和导出。库的上限与恢复策略见 [里程碑说明](MILESTONES-V7.md)。

独立审查复现并修复了迟到恢复预览覆盖新窗口的问题。恢复、重命名、历史报告、合同读取及库列表均在异步返回时检查原窗口是否仍有效。图形时间线也修复了同刻项目互相遮挡的问题，并通过真实鼠标拖动与精确输入验证。

旧功能回归首次有三套因本地 4174 服务未启动而连接拒绝；启动隔离服务后重跑全部通过。原始环境失败和最终唯一计数分别保存，未将重跑重复相加。历史 v0.5/v0.6 验收产物在归档本轮证据后恢复原版本。

## 发布与交付

离线 ZIP 包含游戏、源码、说明、测试及证据，排除依赖目录、Git、运行数据库及凭证。包经 CRC、逐文件 SHA-256 和离线游戏资产与源码逐字节比对；`release.json` 列出文件清单。后续整理说明与证据不更改已通过离线验收的游戏内容。

发布使用已推送的同一源码和生产构建，非敏感发布收据随交付包保存于 `qa/v0.7/deployment.json`。验收完成前不把未发布的 v0.8—v1.0 能力写为现有功能。

# 复杂工程体验 v0.6

本模块把完整电路按画布页面组织，提供真实跨页连接标签、数字导线束折叠、层级搜索和局部端口观察。页面不是独立仿真：隐藏元件仍参与同一个 Runtime，总线束也不会把成员导线电气合并。

## 玩家使用路径

1. 在画布上选择元件，打开「页面与连接」，创建页面后用「移动分组」归类。页面标签显示元件数。未分组对象属于「主画布」。
2. 切换页面后，通向其他页的真实导线显示端点标签。点击标签可查看导线 ID、当前信号及两端位置，再跳转到另一端。标签同名不会自动连接。
3. 「选择真实端点并连接」列出当前层所有页面的现有端点。提交时创建候选导线并执行完整工程校验；位宽、方向、驱动冲突或组合环不合法时不修改当前工程。合法修改需要应用设计后运行。
4. 「总线束」选择同一对元件之间的 2—64 条数字导线，可把它们折叠为带成员数和总位宽的外观。点击画布中的束再次展开。请求和应答方向可以相反；电源和协议事务连接不能加入数字导线束。
5. 「搜索 / 层级」按名称、模型、端口或路径检索最多 200 条结果。「定位 / 观察」保持原仿真现场，定位顶层容器并显示指定内部实例的实际端口；「进入内部」沿真实结构模块打开内部设计。返回上层恢复父层视图与运行快照。
6. 「局部观察」仅显示所选实例端口，可强调其顶层相邻连接。存在未应用设计时显示“待应用”，避免将旧运行现场误认为新设计结果。

页内全选、鼠标/触屏框选、适应画布和自动布局只处理当前显示页面。隐藏元件不会被页内选择误删。非主页面新建或粘贴元件（包括工程边界输入输出）会归入当前页。跨页复制可先通过搜索定位需要的元件或调整页面分组；没有隐式“把全工程都选中”的捷径。

## 真实电路和状态保留

页面新增、重命名、分组、标签和导线束修改只写 view，并作为 `kind:'view'` 进入撤销历史。它们不标记电路待应用、不更换 Runtime、不推进时钟、不暂停正在运行的仿真。切页清除当前选择与尚未完成的画线端点；程序草稿、已应用设计、输入事件队列和运行快照保留。

删除页面必须确认，页内所有元件移回主画布，全部导线保留。删除实际元件或导线时，编辑协调器移除其失效分组/标签引用；成员不足两条的束自动解除。已有撤销/重做会恢复设计和当时的工程视图。视图撤销沿用现有工作台撤销行为，会暂停自动运行。

新导线是真正的设计变更，按既有应用设计规则冷启动。折叠只是几何绘制，成员导线的连接开关仍各自有效；束中存在关闭的线时外观显示断续。需要查看某根线时先展开。

严格工程视图校验发生在 `loadWorkspace` 的备份钩子、暂停及状态替换之前。因此非法导入不会触发备份或部分覆盖原工程。离线作品、JSON 导入导出和运行会话都携带 view；云端沿用同一校验器（服务器与发布由主集成负责）。

## 保存数据契约

`view.engineering` 可省略，旧工程继续显示在主画布。存在时必须完整符合以下结构，未知字段拒绝：

```json
{
  "version": 1,
  "pages": [{"id": "main", "name": "主画布"}],
  "assignments": {"alu": "main", "boundary:result": "main"},
  "wireLabels": {"wire0": "DATA"},
  "bundles": [{"id": "data", "name": "数据束", "wireIds": ["wire0", "wire1"], "collapsed": true}],
  "activePage": "main"
}
```

上例的元件与导线 ID 需在实际工程中存在；示意结构本身不是可直接导入的工程。

- 页面 1—32 个，必须保留 `main`，页面和束 ID 为 `[A-Za-z_][A-Za-z0-9_.-]{0,63}`，名称 1—48 字且不含控制字符。
- assignments 最多 2000 项，只指向当前顶层的实例 ID 或 `boundary:端口ID`。缺省分组为 main；不是通过相同标签合并电路。
- wireLabels 最多 4000 项，标签 1—48 字，只指向当前层的真实导线。删除标签使用删除字典项，不存空字符串。
- bundles 最多 128 个，每束 2—64 条当前层真实数字导线；成员必须连接同一对节点，方向可反。每条导线最多属于一束。
- activePage 必须存在。重复 ID、危险字典键、失效引用、越界数量和错误类型均拒绝。

`EngineeringV6.validate(raw, project)` 用于严格导入，返回独立副本；`normalize(raw, project)` 只用于本地编辑后的悬挂引用清理。二者不能互相替代以静默接受非法导入。全局视图不包含折叠后的伪连线、仿真值或时钟。

## 接口与集成

`game/engineering-v6.js` 提供浏览器 `EngineeringV6` / CommonJS；依赖 CircuitLab，先于 app.js 加载。主要 API：

- `defaults / validate / normalize`：视图数据和校验。
- `nodes / nodeKey / port / pageFor / visibility`：完整设计中的真实节点和显示层投影。
- `hierarchy / search / observe`：层级路径、检索和只读端口观察。
- `connect(project, from, to, id)`：复制工程、添加真实导线并完整校验，失败不改变源工程。

`engineering-ui-v6.js` 位于 app.js 后，样式 `engineering-ui-v6.css`。公开 `EngineeringUIV6.open/search/locate/observe/switchPage`，供测试和入口集成。app.js 的最小 hook 包括：严格 normalizeView；renderGraph、drawWires；visibleNodes/visibleWires；仅视图的撤销与持久化；新增节点分配；载入前原子校验。

房间存在时（包括重连中），页面/标签/束/新导线/内部设计切换不能从本地入口修改。切页使用临时 override，搜索定位及局部观察可用，不写共享工程 view。新页面编辑需退出房间；服务器协作补丁由主集成以 engineering 整体进行冲突校验。

页面分组是当前工作台层级的视图。打开锁定模块内部后是新的可编辑工作台，父层页面视图保存在父层现场中；没有暗中修改原芯片定义或新增跨层级电气连接。

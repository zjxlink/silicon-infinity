# 数据记录器：从应用到自己的程序

v0.7 的“数据记录器”把应用、制作和验证放在同一个工作区。它使用真实 CPU16、输入寄存器、地址译码和外部 RAM。当前样板是本地数字记录器；串口、I²C 传感器和自定义 CPU 中断版不属于这个样板的已实现功能。

## 两分钟运行

1. 点击工程区的“数据记录器”，选择“运行参考作品”。可选“寄存器游标轮询”或“RAM 游标与子程序”，两份真实程序遵守相同目标。
2. 在“应用”填写 0—255 的样本，点击“提交并推进 400 μs”。首次操作会先推进 400 μs 初始化，再提交输入并推进 400 μs；后续提交通常推进 400 μs。
3. 查看记录表与曲线。它们读取程序已经写入、提交的 RAM，不会把输入框的数值直接当作成功结果。
4. 点击“暂停记录”，继续提交不同输入；记录条数保持。点击“开始记录”后，只接收最新样本。
5. 八条后停止追加。点击“清空记录”，待程序确认后再点击“开始记录”。

序号留空时自动加一并按八位回绕。相同序号不会重复记账，即使数值改变；不同序号可以保存相同数值。清空和初始化都把当前输入序号作为基线，因此恢复后没有新的序号不会凭空多一条记录。

开始、暂停记录和清空操作均通过真实控制输入，并推进 400 μs。它们会停止工作台的自动运行，便于观察这一轮结果。调试断点可能提前停止推进；提示显示实际推进的时间，不把未完成操作当作成功。

## 三种起点和三种视角

| 起点 | 保留什么 | 玩家需要完成什么 |
| --- | --- | --- |
| 从接口开始 | 输入设备、公开端口和记录 RAM | 加入 CPU、地址译码并接线、编程 |
| 从骨架开始 | 已接好的总线与初始化程序 | 补上采集、去重、暂停/清空和容量处理 |
| 运行参考作品 | 一份完整可编辑程序与电路 | 先观察，再修改或比较另一种实现 |

**应用**显示当前已应用电路的真实记录。**制作**保留原来的画布、工程分页和程序编辑器。**验证**检查候选设计的独立副本。切换视角不会应用设计、复位电路或消耗输入队列。

顶部同时显示候选设计与运行版本的短指纹。有未应用修改时，应用面板仍显示旧运行版本，输入操作会要求先应用。源码编辑也保留原有“草稿—检查—应用”流程，不能把未编译文本当作已运行程序。

加载起点前会保留原作品完整现场，包括未应用设计、源码、实际快照和输入队列。点击“返回原作品”恢复它。外部载入另一个作品会清除旧返回点；迟到的加载或验证不能把旧作品覆盖回来。已经从文件或作品库载入记录器时，再打开入口会直接观察当前电路，不重新载入参考模板。

## 四个成长目标

1. **写入第一条记录**：序号和值经过真实访存，写数据后再提交条数。
2. **变化输入与去重**：同序号不重复，不同序号允许相同数值，255→0 继续工作。
3. **暂停、恢复与清空**：暂停不追加，恢复取最新输入，清空得到程序确认。
4. **有限缓冲**：容量八条，已满后停止，不覆盖已有数据。

提示逐级展开。原样完整参考通过时标为“参考示范通过”；它不冒充玩家独立完成。进度只保存在本机浏览器，并记录验证时的设计指纹。旧通过记录不保证随后修改仍正确，也不是原创认证。

失败时可以定位首个差异的观察位置，例如记录 RAM。定位显示的是实际检查失败的位置，不武断认定该元件就是根因。应继续检查上游输入、总线与程序。公开角色 `ram`、`sample/control/reset` 及 RAM 布局是本题合同的一部分；改变这些接口需同时建立自己的测试合同。

## 编辑测试与比较方案

“编辑本阶段测试时间线”使用独立的图形时间线编辑器。保存只更新本记录器面板的自定义检查，不改变当前作品、测试台草稿或固定任务目标。“运行我的检查”即使通过，也不会替代四个成长任务的完成记录。

“保存 / 比较个人方案”接入里程碑：保存完整现场、换另一份程序，再固定保存另一方案。比较在双方候选设计的冷启动副本上重新运行共同合同，旧报告仅作附档。面积与存储是游戏指标，不是制造面积或功耗；功能失败不能靠低成本获得通过。

“导出此阶段挑战”使用已有 `chip-game.challenge/1` 文件格式，包含当前候选电路、程序、锁定依赖、提示和固定阶段测试，可离线分享。它不包含当前运行快照；完整现场另存里程碑。

## 操作边界

- 实时表与图最多显示真实容量内的八条已提交记录，没有隐藏的无限记录缓存。
- 暖复位由固件开始空会话，快照恢复保留原会话，两者用途不同。
- 自定义检查、任务验证与方案比较都使用独立副本；取消不改当前工作现场。
- 离开工作区后，旧结果不会抢回视角或覆盖另一个编辑器。
- 共享房间中可以观察、隔离验证和导出；本地载入、输入、应用、程序编辑及恢复都需先离开房间。里程碑操作继续执行自身的权限检查。
- 窄屏下视角栏保持可达，内容区可以滚动；旧工作台和工具入口继续保留。

## 接口与验收记录

`RecorderUIV7` 提供 `open/load/view/submit/verify/cancel/restore/locateFailure/compare/timeline`；只调用 `RecorderV7` 的实际读取与输入方法，不直接写入 RAM。时间线接 `TimelineUIV7.open`，方案比较接 `MilestonesUIV7.openComparison`。

专项真实浏览器脚本为 `tests/browser/recorder-v7.cjs`；结果写入 `qa/v0.7/recorder/recorder-v7.json`，日志为 `qa/v0.7/browser-recorder-v7.log`。同目录保存应用、窄屏、方案比较截图与实际挑战导出。核心电路与合同的测试由 `tests/recorder-v7.test.cjs` 单独记录，不与界面场景数混计。

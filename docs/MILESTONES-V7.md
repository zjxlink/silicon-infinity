# 固定里程碑与双方案比较 v0.7

顶部「里程碑」保存一个命名的完整现场。记录独立于 v4 自动历史，不参与五条历史轮转，不会自动删除。名称、备注可修改；删除需要确认。恢复先展示目标时间，再把恢复前的完整现场固定保存，成功后才替换工作台并暂停。备份容量不足、目标无效或现场在等待期间变化时拒绝恢复。

记录包含现有 `silicon-lab.session/1` 全部内容：当前候选设计及源码、已应用设计、实际运行快照、全部锁定依赖、固件、工程分页与模块来源、父层导航。未编译源码不会被冒充为已运行的程序。导入逐层验证 snapshot 与工程关系；workspace/applied/parents 的视图额外校验，包括 EngineeringV6 的实际引用。

## 存储与离线

优先使用 IndexedDB 的单个 readwrite 事务读取与更新记录，事务完成后才显示保存成功。两个窗口的提交由数据库事务串行化，不靠读取旧 JSON 后覆盖。库最多 64 条固定记录、32 份比较报告、32 MiB UTF-8 序列化数据；完整单条里程碑文件最多 8 MiB。达到上限会拒绝新增并保留原记录，需要玩家明确导出或删除。

只有初始 IndexedDB 不可用或 SecurityError 才进入明确标注的 localStorage 回退，使用独立键 `silicon-infinity.milestones.v7` 与 Web Locks，库预算 4 MiB。没有跨窗口锁的浏览器仅提供读取/文件导出，不假称可靠写入。VersionError、损坏内容或被其他窗口阻止的数据库升级会显式报错，不切换到空库。事务失败或配额失败显示未保存，保留旧记录与当前工作台。IndexedDB 与回退库是独立后端；浏览器权限改变后需要显式文件转移，不自动合并。

本机存档不等于云备份。清理网站数据、浏览器策略或设备故障仍可能使本机数据丢失，请使用「导出当前完整现场」或里程碑「导出」。Chrome 的实际 `file://` 离线入口验证了保存、刷新及文件导入；其他浏览器依实际可用后端显示状态。

「从旧作品库迁入」必须明确点击，只迁入每件作品最近一条记录；迁入前校验全部旧记录及 hash，一次事务提交。原 v4 库原文及全部旧历史保持不变；重复迁入通过来源作品/修订去重。核心 API 可显式请求 all 模式，但数量或容量不足时整批拒绝，不部分覆盖。没有后台自动迁移或自动删除旧库。

v0.8 补充：迁入面板打开期间暂停本窗口的旧库自动备份，已经开始异步校验的备份在提交前检查有效性。迁入读取等待备份队列结束，避免 600 ms 定时备份改写正在迁入的原文。完成、取消、关闭或切换作品都会释放保护，后续修改仍照常备份；已经保存的相同现场不会仅为切换“当前作品”标记而重写原库。此保护不禁止另一个窗口中的用户主动保存自己的作品。

## 两份方案怎样比较

记录器可调用「比较」并交付当前完整 session、固定 v5 测试合同与本次报告。先明确固定保存每份方案，然后在比较区选 A、B；可使用 A 保存的合同或粘贴 v5 合同 JSON。

比较始终用两份保存的候选工程分别冷启动，重新执行同一合同与 seed，使用当前引擎和固定成本规则 `verification-v6-cost/1`。双方应具有合同要求的端点；缺失或不兼容明确报错，不自动连接同名线，不自动缩窄位宽。不使用两个不同历史时刻的 RAM 当作公平起点，也不编译保存的源码草稿。

结果显示实际通过检查、首个失败、游戏面积、存储位和执行状态。只有两个方案都实际通过时才给出面积排序；失败、取消、超预算、端点不兼容不能算通过。游戏面积与存储位复用 VerificationV6 规则，不是物理面积/功耗/频率。现有 LabTestbench 每个方案仍限制 8 秒和 500 万元件×微秒，取消在引擎检查边界生效；本版未加入 Worker。

附档报告只有工程 hash、合同 hash、seed、引擎/成本版本吻合时才可标为作者附带的报告；不一致显示过期。无论附档内容是否声称通过，比较都重新运行。已保存的比较报告锁定候选 sessionHash/projectHash、共同合同、seed、引擎、成本规则和双方完整实际报告；历史报告不认证当前编辑中的工程。可单独查看、导出或删除报告。

比较在隔离 Runtime 中执行，不改变工作台的源码、运行时间、RAM 或事件。取消、切换作品或打开别的编辑对话框后，迟到结果不会覆盖新现场或抢占新窗口。进入共享房间时只允许查看、导出与隔离比较；保存、导入、迁入、删除、改名及恢复在实际存储提交边界再次检查房间状态。

## 接口和集成

- `MilestonesV7.createStore(options)`：异步打开后端；返回 `Store`。
- Store：异步 `list/load/save/rename/remove/export/importPackage/importV4/info/reports/saveComparison/removeReport`。所有读取返回副本。
- `save(session, {name,note,contract?,report?})`：生成带内容指纹的固定记录。
- `MilestonesV7.compare(recordA, recordB, contract, {signal,onProgress})`：返回 `silicon-lab.comparison/1` 固定报告。
- `MilestonesUIV7.open()`：作品入口；`openComparison({session?,contract?,report?})`：记录器接入。省略 session 时立即 capture 当前完整现场。

加载依赖：CircuitLab、WorkspacesV4、LabTestbench、VerificationV6、EngineeringV6、LabAPI，随后 `milestones-v7.js`、`milestones-ui-v7.js` 与样式。模块未修改原 v4 存储、引擎、共享 schema 或云权限。

# 版本发布说明

> 历史版本记录：本文对应原游戏及原托管环境，不是本自托管候选版的 Docker、账号系统或 fnOS 验收。文中的旧 QA 路径、托管发布回执和访问范围仅适用于当时的版本；当前部署与维护请看 [运维说明](OPERATIONS.md)。

## v0.7.0 · 2026-10-10

新增真实 CPU16 本地数据记录器、三种起点和四步需求、应用/制作/验证视图、图形测试时间线，以及命名里程碑和双方案同合同复测。记录器有两种可改程序，只有实际 RAM 提交的数据才显示。存储使用有界 IndexedDB，明确处理不可用、配额和损坏情况；旧库迁入为显式操作。

未新增仿真模型，保留 64 个模型和旧手册；v0.6 快照与原 hash 的挑战兼容。详细行为、资源边界和下一阶段范围见 [本版说明](V0.7-WORKFLOW.md)与 [验收记录](ACCEPTANCE-V0.7.md)。

## v0.6.0 · 2026-10-10

新增复杂工程分页、跨页连线与线束、层级检索；四个各含三阶段的创造任务；按真实展开结构计算的游戏成本；可配置指令集 CPU 与数字协议状态机；有界批量验证、故障对照与四态波形；云端玩家挑战的固定修订、检索、来源和邀请。注册模型 64 个，手册 84 篇。

兼容旧工程和 v0.5 挑战包，固定修订不会自动替换。修复恢复工程后迟到自动备份追加重复历史，以及云端/验证迟到回复覆盖当前编辑窗口的问题。具体入口、资源边界与验收见 [六项说明](V0.6-SIX-ENHANCEMENTS.md)及 [验收记录](ACCEPTANCE-V0.6.md)。网站权限保持原样，真实第二账号联合验收继续按用户决定延后。

## v0.5.0 · 2026-10-10

参数化芯片、开放测试台、CPU16 与 FSM、自定义数字设备、共享总线、DMA、中断控制与双 CPU 系统已实现。范围见 [四阶段说明](V0.5-FOUR-STAGES.md)，历史证据见 [v0.5 验收](ACCEPTANCE-V0.5.md)。

## v0.4.0 · 2026-10-10

新增 12 个独立 MCU 模块，Build8/2 可以通过实际总线和外设执行 GPIO、定时、中断、PWM、UART、SPI、I²C。五个自组装示例保留完整程序与电路，原 Build8/1 和旧芯片定义继续兼容。

新增八主题十二步教学、五个系统应用，以及保存设计草稿和真实运行现场的作品管理。支持自动备份、历史比较、来源明确的模块升级与撤销。复杂电路使用自适应自动运行，长推进可以取消，触屏增加双指缩放等操作。

新增游戏内芯片使用手册与同源离线HTML：ALU完整OP表，52模型的端口与行为，四种MCU的指令、寄存器、复位和读写副作用，18枚结构芯片原版参考。支持元件直达、程序目标入口与地址搜索，阅读保留当前草稿及运行状态。

协作增加持久化待确认操作与断网重连，回复丢失不会重复执行，过期操作不跨运行阶段重放。详细范围和边界见 [六部分说明](V0.4-SIX-PARTS.md)，测试结果见 [本轮验收](ACCEPTANCE-V0.4.md)。正式网站第二真实账号验收按用户决定延后，网站保持原私有范围。

## v0.3.0 · 2026-10-10

本版扩展了从电路编辑、真实调试到自组装处理器与多人实验的完整路径。六部分实现和本地验收已完成；最终网站发布凭证随交付包单列于 qa/v0.3/deployment.json。

### 六部分变化

1. **编辑器**：框选、Shift 多选、组拖动、带内部连线与完整依赖的复制粘贴、批量删除、60 条撤销记录、自动布局、直角理线与端口说明。视图操作不重置运行状态，结构修改继续先校验再应用。
2. **调试台**：真实四态数字波形、MCU PC 断点、指令单步、RAM 查看与 UART/SPI/I²C 事务。运行入口统一经过调试驱动，断点在指令副作用前停止。
3. **硬件库**：新增 24 个独立模型，包含 8/16 位运算、寄存器、RAM、ROM、FIFO、总线拆合、显示及控制元件。总注册模型 40 个，另有原 18 枚结构芯片。提供 4 个硬件实验。
4. **自组装 Build8**：13 个可见元件真实接线执行的处理器，提供 4 个示例、ROM/程序编辑和逐拍观察。PC、取指、译码、ALU、RAM 和输出都从电路本身产生，不使用隐藏 Core8。
5. **挑战**：十个故障工程、三级提示与行为验收。验证在独立副本进行，不推进玩家当前 CPU；进度保存挑战版本与工程 hash。
6. **云库与多人**：Sites 身份、真实 D1 持久化、芯片固定修订、指定修订下载、邀请及撤销。房间使用服务器 Runtime 权威状态、有序 HTTP 操作、控制租约、冲突检测和草稿合并。

### 使用与数据兼容

源码目录从 dist 移至 **game**。当前源码可以直接打开 game/index.html；离线交付仍按“开始游戏.html → dist/index.html”组织，但该 dist 是从 game 复制的独立静态游戏。在线构建生成 dist/server 与 dist/client，两种产物不能混用。

旧工程 schema、Core8/1 语义和不可变定义锁继续保留。新模型按需进入工程；已有芯片版本不自动替换。完整模块、依赖、固件、电源域和 ROM 参数能一起保存、复制与嵌套，重复实例独立。新运行状态的恢复仍需匹配工程与快照合同，不支持把未知模型交给旧版软件运行。

纯页面游玩无需安装。在线开发、服务器构建与完整测试需要 Node.js 22.13.0+、依赖及对应身份和数据库环境。离线入口不需要登录，云端功能需访问已部署网站。

### 明确保留的边界

Build8 是独立教学指令集，8 位累加器、256 字 ROM、256 字节 RAM、每指令两拍，当前为并行字节 I/O。Core8/2 的 UART、PWM、SPI、I²C 和中断仍属于 Core8/2 路线，没有声明为 Build8 已连接外设。

探针记录有限，有采集或断点时每次推进最多 1000 μs。自动布局可能仍有交叉；页面剪贴板不跨刷新。键盘和显示器是数字/ASCII 功能抽象，不模拟电气。

多人采用约 250/900 ms 轮询，没有 WebSocket、Durable Objects 或逐字文本协作。虚拟时间由控制者在线请求驱动，关闭全部页面不会继续后台运行。房间默认预算为 8 人、200 展开节点，另有字节、连线、快照和事件上限。

网站继续保持所有者访问。房间邀请不会改变网站权限，所有者必须在网站分享设置添加受邀者。撤销停止后续授权访问，不删除已下载的离线副本。

## v0.2.0 · 2026-10-10（历史版本）

本版在离线数字工作台上加入可编辑芯片库、完整板封装、文件分享和增强教学 MCU。保留完整文件夹，打开 `dist/index.html` 即可游玩，操作步骤见 [使用说明](../README.md)。

### 新增内容

- **18 枚结构芯片**：半/全加器、多位加法器、寄存器、计数器、译码器、选择器、比较器、移位寄存器、分频器、奇偶校验、上升沿脉冲和小型 ALU。每枚都有真实内部电路，可打开修改。
- **6 块逻辑应用板**：四位计数灯、流水灯、四位加法、独立双寄存器、代码匹配、四种运算。与原 10 个引导实验、4 块新外设板合计 **20 个示例**。
- **16 个核心模型**：新增 Core8/2、SPI 寄存器芯片与 I²C 温度传感器；输入开关、LED 另作视图。库中组合芯片不重复计入基础模型数。
- **Core8/2 外设**：定时器、真实 PWM 数字边沿、定时器/SPI/I²C 中断、带完成时间和错误状态的 SPI/I²C 事务；新增 IRET 返回指令。四个样例为 PWM 呼吸灯、定时中断计数、SPI 写入回读、I²C 测温。
- **完整模块**：MCU、固件、供电和外设可一起封装、重复放置和继续嵌套。实例状态独立，支持观察嵌套 CPU、进入对应程序、逐层返回和保存快照。
- **芯片包文件分享**：导出 `.chip.json`，另一位玩家可导入个人库后复用、打开修改。完整依赖、固件及编辑工程均须一致，失败保留原内容。

### 操作与兼容性

计数与记忆示例可用「逐拍」观察。暂停时输入排队，运行或单步后执行。拓扑修改保持候选状态，源码显示待编译；实际应用后才冷启动。20 个示例均提供目标、提示和独立副本验证，原有 10 关进度单独保留，新增应用板不计入这 10 关。

旧 `core8/1` 的指令与寄存器合同保持不变；新版能力通过 `core8/2` 显式选择，固件目标必须匹配。工程 schema 继续兼容 v0.1，模块包使用独立 v0.2 格式。新软件读取旧工程及兼容快照；旧软件不会自动获得新模型。

普通结构芯片保留版本比较与显式升级。完整模块携带锁定依赖和固件，新版可另行放置，既有实例不会自动替换。

### 当前边界

仍以桌面离线操作为主。PWM 是数字波形，SPI/I²C 是事务模型；不模拟模拟电气参数、物理制造、SPI 逐边沿、I²C 开漏和多主仲裁。GPIO 按键中断、自动消抖和 RV32I 未提供。

文件分享已经实现。在线作品库、账号同步及多人房间仅完成 [设计规格](SHARING-AND-MULTIPLAYER-SPEC.md)，服务尚未上线。

测试范围与最终结果以 [v0.2 验收记录](ACCEPTANCE-V0.2.md) 为准。技术合同见 [芯片库](CHIP-LIBRARY.md)、[MCU 与外设](MCU-V2.md)、[完整板封装](PACKAGING-V2.md)。

## v0.1.0 · 2026-10-10（历史版本）

首个可玩版本提供浏览器单机数字电路工作台，形成连接、运行、验证、封装与保存的基本循环。

### 当时提供的功能

- 进入 10 个实验，从开关、逻辑门、半加器和记忆单元，逐步走到可编程智能灯与 UART 回环。所有实验均可直接进入。
- 使用 13 个核心模型，加上输入开关、LED 输出，连接并观察实际的 0、1、X、Z 信号。
- 运行教学 Core8 程序，查看寄存器、GPIO 与串口接收记录；修改汇编源码后编译并应用。
- 将纯数字电路保存为可复用芯片。多个实例各自保存状态；打开内部后可返回原工作台，修改内容可另存新版本。
- 导入、导出完整工程；单独保存运行快照，保留时间、RAM、队列和在途字节。

智能灯采用参考程序驱动 LED，并发送启动、按下和释放消息。回环实验必须通过实际 UART 连接接收字节后才能点灯；结果由电路与程序决定。

### 当时的操作方式

接线或结构修改先保留为待应用设计，应用后重新启动。源码修改另需编译。暂停时输入变化排队，运行或单步后才生效。已有导线可临时断开、接回，删除导线则属于设计编辑。

验证在独立仿真副本中检查输入输出，允许不同合法实现。封装练习需将新芯片真正接入电路；仅保存到库或放在空白处不能完成目标。

### 当时的边界与验收

桌面操作优先。这是教学用数字功能模型，未实现模拟电压、电流或物理芯片制造仿真。Core8 可编辑程序与连接，不提供可编辑的门级 CPU 图。

v0.1 的 MCU 整板只能保存、导出工程，尚不能自动封装；定时器、PWM、SPI、I²C 和中断当时属于后续方向。这些限制中的整板封装和增强 MCU 外设已在 v0.2 补齐；RV32I、在线库和联机仍未上线。

升级已有自制芯片前可以比较接口、结构和时序合同。小型组合芯片会实际穷举全部二值输入并展示输出差异，复杂或有状态芯片会明确说明比较范围。MCU 遇到未知输入时，诊断指出具体 GPIO 引脚。

历史测试范围与结果见 [v0.1 验收记录](ACCEPTANCE-COVERAGE.md)；该记录保留原版本背景，不替代 v0.2 验收证据。

## 范围与计数口径

本轮包括六部分：编辑器、调试、硬件模型、自组装 Build8、挑战、云端芯片库与多人房间。完成定义与入口见 [V0.3-SIX-PARTS.md](V0.3-SIX-PARTS.md)。

当前内容计数是 40 个注册模型（16 旧模型 + 24 新模型）、18 枚结构芯片、4 个新增硬件实验、4 个 Build8 示例、10 个新增挑战；原实验和应用示例继续保留。模型、结构芯片、示例、挑战是不同单位，不能相加得到“芯片数量”。

测试数字也分两类：核心测试记录表示测试用例，浏览器记录表示业务场景。一个业务场景通常包含多项断言，不把每个断言算成单独流程。不同代理重复运行同一套回归不能累计成新的覆盖数。

## 复现与证据保留

从项目根目录运行，在线开发与完整测试采用 Node 22.13.0+。核心新增测试入口：

```text
node tests/hardware-v3.test.cjs
node tests/builder-mcu.test.cjs
node tests/debugger-v3.test.cjs
node tests/challenges-v3.test.cjs
node tests/cloud-v3.test.cjs
```

浏览器新增入口：

```text
node tests/browser/editor-v3.cjs
node tests/browser/debugger-v3.cjs
node tests/browser/hardware-v3.cjs
node tests/browser/online-v3.cjs
```

真实浏览器脚本需要 Playwright 及可用 Chrome/Chromium；可设置 CHROME_PATH。静态预览应实际服务当前 game 目录，不能误用旧 dist。硬件和分发测试使用独立浏览器上下文，不读取玩家日常数据。在线测试需要实际服务与对应身份/数据库环境；本地 SQLite D1 适配测试不能单独证明生产 D1 部署已经工作。

npm test 已包含全部 14 套；浏览器复现入口与环境见 tests/browser/README.md。对解压包的禁网验证已独立执行。

机器可读结果放 test-results/browser；发布时选取本轮最终结果复制到独立 v0.3 证据目录，并记录运行环境、时间和对应源码。截图用于解释页面，不能取代行为断言。

## 已知边界，不计作假通过

- 数字功能级仿真不包含模拟电气、制造、PCB 布线、SPI 逐边沿或 I²C 开漏多主仲裁。
- Core8/2 外设与 Build8 分开。Build8 当前为并行字节 I/O，不宣称已拥有 Core8/2 的 UART/PWM/SPI/I²C/IRQ。
- PC 断点针对 Core8 MCU 指令；Build8 通过真实两拍硬件观察和步进，不把它伪装成 Core8 指令地址。
- 调试记录和资源有明确上限；捕获在每整数微秒稳定后执行，不观察该微秒内部的组合瞬态。
- 多人为有序 HTTP + 250/900 ms 轮询，不是 WebSocket/DO；没有无客户端常驻运行和逐字 CRDT 编辑。
- 房间邀请码只授予资源权限。网站目前仍是所有者访问，必须在网站分享设置另外添加受邀者。未实际操作第二位有网站访问权的用户时，应把对应生产权限场景标为未验证。
- 当前浏览器证据以 Chrome 为主；窄视口通过不等同于全部真实触屏设备、Safari/Firefox、无障碍和性能规模都已覆盖。
- 云端超预算会拒绝，离线更大工程不保证可直接转为房间。发布和快照包含不同信息，设计打开按初值开始，不能声称自动继续旧执行状态。

# 可编辑芯片库

版本：0.2.0 · 日期：2026-10-10

本库新增 18 枚结构芯片和 6 块应用板。每枚芯片都由现有逻辑门、选择器和 DFF 组成，可以打开内部连线、修改并另存；它们不是只改变外观的图标，也没有增加未经定义的硬件模型。

## 先了解引脚

多位数字使用一组一位引脚表示，编号 0 始终是最低位。例如 `a0=1、a1=0、a2=1、a3=0` 表示十进制 5。`a0..a3` 表示四个独立引脚，不是一个尚未实现的总线连接器。

所有时序芯片冷启动为零，共享每 1 微秒一次的时钟。`EN=1` 允许下一拍更新，`EN=0` 保持；`RESET=1` 在下一拍清零，优先于 EN。暂停时可先设置多个输入，再单步，让它们在同一拍生效。

计数和流水灯建议逐拍观察。一次推进 1000 微秒可能越过许多完整周期，前后看见相同结果并不表示电路停止。各时序示例提供 `suggestedStepUs:1`，内核时钟规则保持不变。

## 18 枚芯片

下表均可作为完整设计打开，也可作为一枚芯片放入其他电路。输出名称与大小写显示名可以不同，端口 ID 以表中小写名称为准。

| 芯片 / ID | 输入 | 输出 | 功能与用法 |
|---|---|---|---|
| 半加器 / `half-adder` | `a,b` | `sum,carry` | 两个一位数相加；结果为 SUM + 2×CARRY。 |
| 全加器 / `full-adder` | `a,b,cin` | `sum,carry` | 相加时包括 CIN，可连接前一级进位。 |
| 2 位加法器 / `adder2` | `a0..a1,b0..b1,cin` | `s0..s1,carry` | 计算 A+B+CIN；CARRY 是第 3 位。 |
| 4 位加法器 / `adder4` | `a0..a3,b0..b3,cin` | `s0..s3,carry` | 计算两个 0—15 的数及输入进位；CARRY 是第 5 位。 |
| 2 位寄存器 / `register2` | `d0..d1,en,reset` | `q0..q1` | 同时记住两位数据，关闭 EN 后保持。 |
| 4 位寄存器 / `register4` | `d0..d3,en,reset` | `q0..q3` | 同时记住四位数据，可独立复制多份。 |
| 2 位计数器 / `counter2` | `en,reset` | `q0..q1` | 更新顺序 0、1、2、3、0；关闭 EN 可停在任意数。 |
| 4 位计数器 / `counter4` | `en,reset` | `q0..q3` | 从 0 数到 15 后回到 0。 |
| 2—4 译码器 / `decoder2x4` | `a0,a1` | `y0..y3` | 把二位数转成四选一；仅编号等于 A 的输出为 1。 |
| 四选一选择器 / `mux4` | `d0..d3,sel0,sel1` | `out` | SEL=sel0+2×sel1；OUT 跟随选中的数据输入。 |
| 2 位比较器 / `comparator2` | `a0..a1,b0..b1` | `gt,eq,lt` | 分别表示 A>B、A=B、A<B；已知输入下只有一个输出为 1。 |
| 一位记忆 / `d-memory` | `d,en,reset` | `q` | 一枚 DFF 的可复用封装，便于查看与修改控制连接。 |
| 4 位移位寄存器 / `shift4` | `din,en,reset` | `q0..q3` | 每次更新将 DIN 写入 q0，其余位依次接收低一位的旧值；q3 可作串行输出。 |
| 二分频器 / `divider2` | `en,reset` | `q` | 允许更新时每拍翻转；输出完整周期为两个时钟周期。 |
| 4 位奇偶校验 / `parity4` | `d0..d3` | `odd,even` | 数据中 1 的个数为奇数时 ODD=1，否则 EVEN=1。 |
| 一分四分配器 / `demux4` | `din,sel0,sel1` | `y0..y3` | 选中的一路跟随 DIN，其余输出 0。 |
| 上升沿脉冲 / `edge-pulse` | `din,en,reset` | `pulse` | 两级记忆比较前后采样；检测到 0→1 后输出一拍高。 |
| 2 位逻辑算术单元 / `alu2` | `a0..a1,b0..b1,op0,op1,cin` | `r0,r1,carry` | OP 为 0/1/2/3 时依次执行与、或、异或、加法；仅加法使用 CIN 并输出进位。 |

上升沿脉冲有一条额外规则：EN=0 时停止采样并使 PULSE=0。恢复使能后，会与上次保留的采样比较；输入一直为高不会每拍重复产生脉冲。RESET 清空两级记忆，因此复位解除后第一次采到高电平也会产生一次脉冲。

这些功能表描述已知的 0/1 输入。X、Z 和驱动冲突继续遵循统一内核规则，不会被偷偷当成零。

## 6 块组合应用板

| 应用板 / ID | 可以观察什么 | 建议操作 |
|---|---|---|
| 四位计数灯 / `counter-display` | 四位计数器直接驱动四盏灯 | 连续单步观察二进制递增，再关闭 EN 或置 RESET=1。 |
| 四路流水灯 / `running-lights` | 计数器与译码器组合，四盏灯依次亮 | EN=1 单步；EN=0 保持；RESET=1 回到第一盏。 |
| 四位加法实验板 / `arithmetic-board` | 四位加法器的完整五位结果 | 输入 A=15、B=1、CIN=0，观察低四位清零而 CARRY 点亮。 |
| 两份独立记忆 / `dual-registers` | 同一定义的两个实例互不覆盖 | A 写入 3 后关闭 EN_A，让 B 写入 1；A 仍保留 3。 |
| 二位代码匹配器 / `code-match` | 比较器与非门组合，匹配与不匹配灯互斥 | 设置 CODE，再改变 KEY；两者相等时 MATCH 亮。 |
| 四种运算实验板 / `mini-alu` | 同一输入在四种运算下得到不同结果 | 固定 A=1、B=3，依次切换 OP=0、1、2、3。 |

应用板中使用的库芯片也保留真实内部结构。修改、封装版本、返回上层和工程导出沿用工作台原有流程。

## 数据接口

脚本文件为 `dist/chip-library.js`，浏览器全局名 `ChipLibrary`；Node 可用 CommonJS 导入。加载顺序为电路内核在前、芯片库在后。

| API | 返回内容 |
|---|---|
| `list` | 18 枚芯片的 ID、名称、分类、说明、使用方式、端口、是否含记忆与可编辑标记 |
| `boards` | 6 块应用板的 ID、名称、分类、说明和建议运行步长 |
| `await build(id)` | `{project,view}`，完整可编辑电路与节点位置 |
| `await entry(id)` | `{definition,dependencies,project,view}`，用于作为芯片放入其他工程 |
| `await buildBoard(id)` | `{project,view}`，含真实库芯片实例的应用板 |
| `await verify(id,project?)` | `{ok,checks}`，芯片行为验证；省略工程时验证标准构建结果 |
| `await verifyBoard(id,project?)` | `{ok,checks}`，应用板行为验证 |

库定义使用 `lib.` 前缀，将 ID 中的连字符换为下划线，初始版本均为 revision 1。例如 `half-adder` 对应 `lib.half_adder`。每次构建返回独立数据，依赖包含实际使用的锁定定义，哈希由内核生成；不依赖随机节点名称或执行任意脚本。

端口均为一位数字类型；组合芯片没有隐藏状态。时序芯片的内部 DFF 状态按实例路径分别保存，封装和再次嵌套不会使不同实例共享记忆。

## 验证范围

`tests/chip-library.test.cjs` 对每枚组合芯片穷举全部 0/1 输入；对每枚时序芯片执行写入、保持、复位及连续更新脚本。验证在原电路和封装后的实例上各运行一次。

另外检查六块板的实际输出与导出后重开行为、二层嵌套寄存器的独立状态、确定性哈希以及断开关键线路时必须失败。结构和资源检查继续由内核负责；本库未修改 1000 个实例、4000 根导线等限制，也没有修改 MCU 或信号合同。

此库仍属于数字教学仿真，不包含模拟电气参数、现实器件延迟或可制造版图。

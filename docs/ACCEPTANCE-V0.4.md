## 浏览器与性能测量

Chrome 154、Edge 155、Firefox 153、WebKit 26.5 在同一台 Windows 主机执行八项共同流程，共 **32 项**通过。包括实际运行/暂停、端口接线、I²C 温度输入、自组装定时中断、作品现场恢复、窄屏触摸缩放、200 寄存器自动运行暂停响应和长推进取消。逐浏览器版本、实际暂停耗时与截图见 `qa/v0.4/compatibility.json`。

这是桌面浏览器引擎检查；触屏使用浏览器触摸事件和 Chrome CDP 触摸注入，不声称已验证物理手机、真实 iOS Safari 或全部辅助技术。

手册加入后的兼容复测中，Windows WebKit 首次末项测试等待挂起，被中止并保留原记录；测试补充分步骤超时后，隔离重跑全部八项通过，断言未减弱，未复现产品退化。最终四引擎结果见同一份 `compatibility.json`。

`qa/v0.4/performance.json` 记录当前主机的实际测量：1000 节点/1050 连线校验和创建约 105 ms；100 次完整输入传播约 1489 ms，共核对 5000 个输出；保存/恢复约 76 ms；200 寄存器的 1000 个真实边沿约 1826 ms。结果依赖主机与电路结构，不是所有设备的性能保证。自动运行根据实际耗时缩小批量，重电路长推进允许取消，不跳过已推进的虚拟时刻。

## 联机、生产构建与离线包

真实浏览器已验证回复丢失后不重复执行、离线请求恢复、过期操作丢弃、编辑回复丢失和撤销访问。集成审查发现的退出后迟到回复、草稿返回和旁观状态绕过入口均已修复。生命周期 11、重连 5、原在线 11、云库分页 6，共 33 个浏览器场景通过，见 `qa/v0.4/browser/room-regression-summary.json`。

八客户端持续运行记录：`qa/v0.4/soak-30min.json`。长测构建指纹见 `qa/v0.4/soak-build.json`；期间用户补充了芯片手册需求，后续只新增静态手册与界面入口，仿真及 API 的七个输入文件保持一致。最终重新构建记录在 `qa/v0.4/final-build.json`，由 `scripts/verify-release-v4.cjs` 核对两阶段的仿真/API 输入与最终构建。长测的 `complete` 与实际 `elapsedMilliseconds` 是完成证据；使用本地构建 Worker、真实本地 D1、一个运行者和七个并发观察者，包含重试、控制租约到期与撤销再邀请。它不等价于八个真实账号，也不代表真实互联网或生产承载压测。

首次持续测试在约 22.6 分钟、10,804 次请求后因本地测试进程内存耗尽而中断，不计为通过；原始结果保留在 `qa/v0.4/soak-first-attempt.json`。后续隔离检查发现本地调试代理在没有调试器消费时持续缓存网络消息；复测使用公开本地启动接口关闭调试通道，未修改游戏代码、依赖源码或提高堆上限。实际应用与 SQLite 的 16,000 次隔离请求另记录在 `qa/v0.4/memory-core.json`。详细诊断和适用边界见 [本地 Worker 验证说明](LOCAL-WORKER-VALIDATION-V4.md)，不能将测试工具的内存测量直接解释为线上服务容量。

最终构建 API 与数据库检查见 `qa/v0.4/worker-d1.json`，包括静态资产逐字节一致、身份要求、新版源码与来源信息、真实 Build8/2 I²C、权限撤销以及完整芯片发布和下载运行。构建由 Sites 官方构建流程生成；网站发布记录随交付包保存于 `qa/v0.4/deployment.json`，不含登录或部署密钥。

离线 ZIP 必须实际解压，检查每个文件的大小和 SHA-256，再在禁网浏览器中验证新脚本、自组装 MCU、程序修改、作品现场、课程返回与离线提示。结果见 `qa/v0.4/offline-v4.json`。ZIP 内 `release.json` 保存逐文件清单，外部 `.sha256` 校验整个 ZIP。

## 明确保留的验收例外

用户暂时没有第二个真实账号，并明确要求先完成其他工作。因此正式网站的第二账号登录、跨账号邀请、撤销和重连验收尚未执行。网站保持原先仅所有者可访问的设置；后续需先为另一账号开放网站访问，再执行房间邀请流程。

本版是数字功能级游戏：无模拟电气、晶体管制造、真实 ARM/RISC-V 指令兼容或逐线 I²C/SPI 电气仿真。Build8/2 是单层中断教学架构。本地存储不是云备份；二十个作品、每个五条历史和约 4 MiB 配额是明确上限。共享房间最多八人、二百个展开节点，关闭全部页面后不会持续推进电路。

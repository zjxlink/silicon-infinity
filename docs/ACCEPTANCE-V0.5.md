范围为 [四阶段交付说明](V0.5-FOUR-STAGES.md)。所有计数来自本轮实际日志，旧版记录作为历史材料单独保留。最终资产指纹、聚合结果与验收范围见 `qa/v0.5/final-verification.json`，可用 `scripts/verify-release-v5.cjs` 复核。

## 核心与浏览器

完整核心回归 **509 项 / 28 套** 全部通过，日志为 `qa/v0.5/core-tests-final.log`。包含原有 415 项，以及参数模板 7、性能等价 5、测试台 23、CPU 与控制器 19、系统总线 36、新云端集成 4。

旧浏览器回归 **102 场景 / 11 套** 全部通过：工作台 12、细节 6、芯片升级 3、故障诊断 1、v0.2 扩展 14、编辑器 10、调试器 8、硬件 10、旧离线扩展 7、教学与应用 19、手册 12。汇总与各项报告位于 `qa/v0.5/browser/legacy/`。

新功能浏览器验证共 **41 个场景**：参数与系统观察 7、架构实验室 9、系统总线 11、测试台 14。覆盖真实程序编辑、源码断点、写入前观察点、RAM 结果、DMA 实际事务、双 CPU 公平进展、测试隔离、反例重演、模板生成/封装/导出、共享房间保护与 390px 布局。对应日志、JSON 与截图位于 `qa/v0.5/` 和其 `browser/` 子目录。

Chrome 154.0.8037.98、Edge 155.0.4283.45、Firefox 153.0、WebKit 26.5 各 **11 个场景**通过，共 **44 项**，无页面异常。包括旧的运行、接线、I²C、组装 MCU、保存恢复与触摸缩放，以及新 CPU+DMA 搬运、参数化寄存器组、通过后真实断线产生失败的开放测试。200 寄存器电路暂停响应分别为 319.75、193.65、938.49、748.54 ms；长推进可中止，取消后时间不再继续。完整记录为 `qa/v0.5/compatibility-v5.json`。

浏览器触屏使用模拟环境，WebKit 是 Windows 测试引擎；没有宣称完成实体手机或真实 iOS Safari 的硬件验收。

## 正确性边界与交叉审查

优化求解与参考求解比较完整快照和事件，覆盖四态输入、驱动冲突、复位、连接开关、I²C、中断、千节点作品和复杂总线。三类最终性能测量均保持结果一致，具体时间见 `qa/v0.5/performance.json`。

交叉审查发现并修复了复位线未知时复用旧 READY/RDATA 的实际缺陷。最终 Systems 回归覆盖 RAM 与寄存器取消写入、仲裁器取消请求、DMA 取消，以及 CPU 在断线后不会读到上一笔值并错误宣称成功。未知复位立即屏蔽总线有效响应，在途操作取消，重新武装必须经历明确空闲。修复已纳入最终 36 项系统测试与全部回归。

手册覆盖全部 **62 个注册模型**的每个端口，并提供 ALU OP、CPU 指令、寄存器访问属性、复位值与副作用。独立 HTML 由同源数据生成，共 **82 篇条目**。新四阶段规格明确标注字地址、采样时刻、DMA/IRQ/栈限制，以及未知输入、错误和断线语义。

## 实际服务器与持续联机

Sites 官方流程生成生产构建，日志为 `qa/v0.5/build.log`。实际本地 Worker 与持久化 D1 执行 **6 项检查**：所有游戏资产逐字节相同、身份要求、三套系统工程和源码保存、CPU+DMA+IRQ 与独立运行逐步全等、查看者权限/撤销、完整双 CPU 芯片发布下载后真实执行。见 `qa/v0.5/worker-d1.json`。

另运行 **5 分钟、8 个本地隔离身份**持续检查：一个控制者与七个并发观察者；CPU16、DMA、中断和共享 RAM 持续推进。检查观察快照与版本全等、重复请求不重复执行、控制租约到期后重连、撤销七个观察者后拒绝访问再重新邀请、事务日志有界。完成状态、实际请求数、延迟和时长以 `qa/v0.5/soak-systems.json` 为准。此测试不是八个生产账号，也不代表互联网或生产容量测试。

最终启动器关闭本地调试检查器，沿用已验证的 Worker 预览方式；未修改依赖实现或提高内存上限。公开生产站点保持原来的访问范围。发布回执随交付包保存到 `qa/v0.5/deployment.json`，不包含访问密钥。

## 离线交付

ZIP 已实际解压，并逐文件检查大小、SHA-256 和 CRC。解压后禁网浏览器完成 **6 项离线场景**：版本与功能加载、实际 I²C 结果、程序修改、草稿及队列保存、课程返回现场、离线云端入口说明。新参数与系统观察的 **7 项场景**也对该解压包执行通过。后者属于前述 41 项新功能检查，未重复计数。

离线游戏文件与生产构建、最终源码逐字节比对。最后只补入文档、证据与发布回执，不更换已验证的游戏资产。包内 `release.json` 是逐文件清单，外部 `.sha256` 校验 ZIP。离线从 `开始游戏.html` 进入；网站功能需要联网及相应授权。

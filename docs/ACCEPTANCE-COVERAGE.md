## 明确的首版边界

本版已运行的是功能级数字模型：供电域开关控制执行和驱动，不计算模拟电压、电流；Core8 是教学自定义指令集，UART 是固定 9600、8N1、每字节 1042 µs 的事务模型。PWM、中断消抖、I²C、SPI、RV32I 核心、网络协作和共享芯片库均为后续内容，X01—X04 不计入本次通过数量。

版本升级对最多 6 个输入位的纯组合芯片穷举二值真值表；更大电路及有状态芯片会明确显示未穷举，不能把这种预览称为全面形式验证。芯片整板自动封装差异 T29 需要后续实现及独立验收，本报告不替用户做验收豁免决定。

## 分发回归补充

隔离验收曾发现缩放后放入芯片的位置小数会被严格 JSON 解析器拒绝。现已将放置坐标及所有工作区导出的布局规范化为整数，再重新解压、导入和执行验证。两项分发检查通过；不是仅检查 ZIP 能解压。设计数据、固件和运行求值未放宽校验。

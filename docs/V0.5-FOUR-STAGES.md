# v0.5 四阶段交付说明

交付日期：2026-10-10（America/Los_Angeles）。版本：0.5.0。

这轮将“自由创造复杂数字系统”落实为五个工作台入口。玩家可以先使用现成芯片，再修改参数、控制表、程序与接线；可以给自己的作品写测试，比较不同结构，最后封装并分享完整系统。旧作品、教学 MCU、Build8、系统应用与在线房间继续保留。

| 阶段 | 游戏入口 | 本版可实际完成的事情 |
|---|---|---|
| 1：复用与开放验证 | 参数芯片、测试台 | 一份模板生成不同位宽/容量的电路；公开自己电路的整数参数；写输入时间线和预期结果；重演首个反例；用多种结构完成同一题目。 |
| 2：可编程架构 | 架构实验室 | CPU16 间接寻址、子程序、栈、中断；修改状态机；自定义寄存器设备；源码断点和访存观察点。 |
| 3：复杂系统 | 系统总线 | 配置地址窗口、RAM 与设备；让 CPU 和 DMA 竞争真实总线；搬运内存、进入中断；运行双 CPU 共享存储器。 |
| 4：规模与共创 | 系统观察、测试台、在线实验室 | 查看展开成本和信号来源；比较优化与参考仿真；保存和交换玩家挑战；把完整复杂芯片发布到现有共享库，并在权限控制的房间中共同编辑/运行。 |

## 建议的游玩顺序

1. 打开“参数芯片”，选择消息队列，设置 16 位、容量 3，点击“打开内部电路”。依次推入 100、101、102，观察满标志与出队值；再次推入可看到溢出错误。也可以放入现有设计。
2. 打开“测试台”，选择“两个条件不同时点灯”。从公开接口开始，自行组合门电路；失败时看第一处反例，成功后比较三个参考结构。判定依据是输入输出行为。
3. 打开“架构实验室”的“数组求和与子程序”。运行后外部 RAM[16] 应为 36。阅读 CPU16 手册，在 STORE 所在源码行设置断点，观察写入前后的寄存器和实际内存。
4. 打开“系统总线”的“CPU + DMA · 共享系统总线”。触发 DMA，推进 100 拍，RAM[64…67] 应为 17、34、51、68；查看两主端获准次数、DMA 完成和中断确认。CPU 的正常工作继续推进。
5. 运行“双CPU · 共享RAM”。两颗 CPU 分别更新地址 0、1。修改一个程序后重新应用，再看总线竞争和各自退休指令数；不要假设读改写自动具备原子性。
6. 为自己的作品编写测试与提示，导出玩家挑战文件；或把整个系统封装为芯片并发布到有权访问的芯片库。挑战包锁定设计与测试，可以导入后改造并另存。

## 自由度如何落到实际行为

参数模板会生成可以打开、修改、封装的真实电路。自己的模板可公开现有元件的整数参数，包括嵌套模块内的参数；每次生成都重算依赖签名并检查范围。内置寄存器组支持 8/16 位、1—8 个寄存器；FIFO 支持 8/16 位、1—256 项。自定义模板不执行脚本，改参数不会绕过芯片合同。

CPU16 有 8 个 16 位寄存器、1024 条指令的程序 ROM、64 词调用/数据共用栈与最多 4 层中断现场。数据读取和写入必须经过外部总线。它是教学处理器模型；想观察分开的 PC、译码、ALU、RAM 组成过程仍可用 Build8/2。两种深度可以并行探索。

状态机由玩家编辑状态、输出与转移表。自定义设备支持地址、复位值、RO/RW/W1C/RC 权限和外部输入映射。该设备使用本版 16 位请求/应答寄存器总线；现有 UART/SPI/I²C 芯片继续使用原合同。任意模拟器插件、用户自编 UART/I²C 逐边沿协议并未纳入本版。

测试台支持确定种子的随机输入、端口与状态检查、已知值/范围/端口关系检查，以及按时刻采样的不变量。首个失败可以重新运行验证并查看逐采样记录。测试在隔离副本中执行，原作品的草稿、输入队列和运行现场保持完整。通过仅表示满足声明的检查；玩家仍需为自己的功能补充完整测试。

## 复杂系统与规模

仲裁器支持两个主端，译码器支持两个不重叠的地址窗口；通过显式接线组成系统。DMA 是单通道逐词搬运。IRQ 控制器有四路请求与优先级，CPU 保存并恢复中断现场。没有缓存一致性、原子指令、多通道 DMA、自动布线或物理时序收敛模型。

本地预算仍为 1000 个展开实例、4000 条导线、128 个定义和 16 层嵌套；协作房间仍为 200 个展开实例、800 条导线和最多 8 人。资源面板按展开后计算，封装不会隐藏成本。芯片数量与组合空间可以持续扩展，单次运行受这些预算约束。

性能改进缓存未变化的网络解析和组合输出，同时保留原参考求解器。没有跳过时钟拍、通信事件或中断。资源面板可在隔离副本比较两种结果，并允许取消。测量说明和实测数据见 [参数与性能说明](PARAMETERS-PERFORMANCE-V5.md)。

## 保存、分享和协作

参数模板使用独立 JSON 文件；玩家挑战文件包含锁定的设计、测试、种子与提示。挑战当前通过文件交换并可保存到 8 个本机槽位；尚无云端挑战排行榜或在线挑战商店。

芯片共享与房间沿用现有网站能力。新 CPU 的已应用源码包含在芯片参数中，工程中的未应用源码另存；完整模块下载后仍能查看内部并修改。服务器执行和保存共同仿真，同一个操作重复送达不会重复执行。编辑有冲突检查和查看/编辑角色。

正式网站仍只有所有者可访问。用户已选择暂缓需要第二个真实账号的生产验收；本轮使用本地隔离身份验证权限、一致性、重连和撤销。站点分享授权与房间邀请码是两层不同权限。

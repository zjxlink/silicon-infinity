# 图形测试时间线

从顶部「测试台」进入「图形时间线」，或在记录器的验证视图编辑本地测试。三个轨道分别显示输入事件、时刻检查和区间规则。先选择项目，再拖动或输入精确微秒；也可以复制、删除。相同或相邻时刻的项目错开显示，图形排序不会更改同刻事件的执行顺序。

输入表单支持数字输入、暖/冷复位、连线启停、温度和串口字节。行为表单支持指定时刻、截止时刻检查、按固定间隔的保持采样，以及相等、范围、已知值比较。输入用边界端口名，检查用完整端口路径，例如 `$.y`。表单旁列出目标命名规则。

截止检查只检查截止时刻的实际状态，不断言此前是否曾短暂响应。保持采样将区间展开成真实检查，不能证明两个采样点之间始终成立。验证能力以实际测试合同为准；复杂条件仍可在高级 JSON 配置。

数据沿用 `chip-game.testbench/1`，没有引入平行测试语言。已有状态检查、表达式、随机源和区间规则完整保留，统一通过现有校验器。原始 JSON、事件时刻、种子或范围不合法时整个修改被拒绝。轨道各显示前 300 项，完整合同仍保留在 JSON 与导出文件；保持采样遵守 2048 条检查预算。

所有编辑先进入弹窗草稿。点「保存时间线」才提交给调用工具，关闭放弃本次修改。保存不应用接线、不编译程序、不推进实时电路。调用工具检查草稿是否已过期，较晚回复不能覆盖新的目标；共享房间内禁止编辑本地时间线。

验收包含真实 AND 电路的正例与失败反例、同刻事件、拖动、精确输入、复制删除、原子拒绝、高级配置往返、过期回复及窄屏布局。核心和四浏览器证据见 `qa/v0.7`。

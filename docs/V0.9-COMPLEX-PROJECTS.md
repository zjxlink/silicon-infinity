# v0.9 · 复杂作品实验室

本阶段围绕已有完整 MCU 终端增加调试、后台计算、固定工程修订和多方案比较。原有逻辑门、芯片封装、图形设计器、程序、任务、手册与共享房间继续使用同一套数字仿真模型。

## 从完整作品开始

1. 打开「完整 MCU 终端」，选择固定核心或自定义核心。先运行到产生采样记录，再进入电路与程序查看 CPU、DMA、串行适配器和真实连线。
2. 在「追踪与回放」选择内部路径和端口，设置条件触发并观察触发前后记录。追踪来自仿真事件与真实采样，模块路径不会因封装消失。
3. 保留捕获中的检查点与输入日志，在隔离副本中回放。完整终态一致才显示复现成功；记录不完整时会说明原因。
4. 使用「后台计算」载入当前已应用的运行现场，在后台副本中推进、输入、复位与观察。暂停后可明确回填；原工作台发生变化或进入共享房间时，旧结果不能替换它。
5. 在「工程库 / 比较」固定保存设计、已应用版本、源码和运行现场。选取至少三个方案，用同一测试与输入负载重新比较各项指标。

详细操作见 [追踪与回放](TRACE-V9.md)、[后台计算](COMPUTE-V9.md)、[工程库与方案比较](PROJECTS-AND-COMPARISON-V9.md)。所有工具直接开放，不需要解锁；参考样板可以拆开、编辑和重新封装。

## 同一参考引擎与后台副本

Web Worker 使用与工作台相同的模型和求解器。请求携带工程指纹、版本、运行代次和命令序号；取消、关闭与切换工程均使不匹配的结果失效。实时后台运行是独立现场，原运行按钮及执行前断点仍由原工作台控制。

离线文件模式使用本地隔离、分批推进的回退实现，并明确显示模式。回退不会伪装为后台线程。隔离验证从设计的初始状态启动；实时后台现场可以从当前快照继续，两种起点在界面上区分。

## 可观测性与回放边界

原生运行观察接口在输入入队、生效处理、共同采样前、提交后、问题出现、协议路由创建与协议完成时发出记录。观察器不占用引擎事件序号、不进入运行快照；未启用追踪时不构造追踪快照。

协议记录使用实际路由 token 的请求编号。数字总线记录来自请求和应答的真实信号及已连接网络。跨模块显示不自动断言未观察到的因果关系。路由创建也不等同于设备已受理请求。

条件触发在当前仿真拍提交后停止，保留该拍结果。前后缓冲、输入日志、事件和检查点均有预算；截断计数与回放资格应与捕获一同导出。回放不改变原工作台，不以重播动画代替执行电路。

## 规模与性能

「规模检查」提供九种真实样板：100/500/1000 门组合链、64/256 级寄存器链、64 个八门模块组成的嵌套阵列、CPU 与 DMA 共享总线，以及两种完整终端。

测量对当前求解器与保留的参考求解器逐拍比较完整快照，使用固定输入变化、未知状态与暖复位负载；每次显示节点数、导线数、快照大小、累计耗时和每拍 P95。测量副本不会覆盖工作台。样板也能直接打开，继续编辑。

本版本地上限仍为 1000 个展开节点、4000 条展开导线。共享房间保持 200 个节点、800 条导线的独立预算。模块封装不会隐藏展开成本。样板通过不代表所有同规模电路具有相同速度；参考终端本身仍为可修改的八条记录教学应用。

持续运行验收要求至少 30 分钟墙钟，检查实际虚拟推进、请求数量、日志界限、内存趋势和暂停响应。验收结果另见本版验收记录；不以短跑推算代替持续运行。

## 存储与比较

新工程库使用浏览器 IndexedDB，固定修订和旧版自动历史分别保存。旧库只在玩家明确迁入后出现在新库中，迁入完成依赖事务成功；旧原文保留。配额不足、数据损坏或事务失败不会默认为成功。

工程库容量预算不等于浏览器保证可用容量，也不是云备份。重要作品仍应导出。离线文件模式、隐私设置和浏览器清理对持久化的影响由实际运行环境决定，界面显示存储不可用时仍可使用原工作台及导出。

多方案比较固定测试版本、输入负载、随机种子、引擎和成本规则。面积、已识别容量、数字采样时延、吞吐与失败证据分别展示；未完成或不适用的指标不填造数值。功能正确不因面积较大而失去通过资格。这里的面积是游戏权重、时延是数字仿真观察值，不是硅片物理签核。

## 后续范围

本版不增加晶体管级模拟、商用 MCU 工具链或无限规模承诺。可视化出题、题目质量报告、作品发现与完整派生分享属于后续 v1.0 候选阶段。网站访问范围保留，第二个真实账号的生产验收继续按用户决定延后。

# 参数芯片与复杂电路观察

版本：0.5.0。

## 参数模板

“参数芯片”内置寄存器组与消息队列两种模板。位宽可选 8 或 16；寄存器数量 1—8，初值必须符合位宽；队列容量 1—256。点击“验证配置”只生成和验证副本，“打开内部电路”载入生成结果，“放入当前工程”添加完整模块并成为可撤销的候选设计，应用后才改变运行现场。

选择“把自己的电路变成模板”，勾选要公开的现有整数元件参数。嵌套模块中的参数也可选。模板只允许约定的参数路径，不能改对象原型、模型身份或任意字段；生成后重新锁定依赖并执行完整工程验证。宽度改变如导致接线不匹配会被拒绝，不自动截断导线。

模板格式为 `silicon-lab.template/1`，包含 id、revision、name、factory、parameters、bindings、workspace、contentHash。同一模板和同一参数配置生成确定的 specialization 哈希。不同放置实例有独立运行状态；分享模板不等于分享正在运行的 RAM。

本机模板库最多 40 项、2 MiB；单个模板导入限 1.5 MB。参数字段最多 32 项，均为有界非负安全整数。长配置摘要在工程名称中截至 70 字，完整配置仍保存在生成结果与模板中。重要作品应导出文件备份。

## 系统观察

面板统计当前设计展开后的实例、导线、定义、状态模块、信号位与当前快照大小，并列出各顶层模块内部成本。选择数字端口后，可沿组合依赖查看驱动源、接收端与驱动冲突；追踪遇到寄存器等状态边界停止，最多 256 个网络。它展示当前连接因果；历史行为使用波形与测试台重演。

性能检查从当前设计的冷启动副本开始，分别执行优化与参考求解器，并比较完整状态和事件。可推进 1—2000 虚拟微秒，中途可取消；不会推进当前运行现场。界面测量包含主动让出界面的时间，因此它不是芯片物理频率指标。

优化使用数字四态向量、驱动集合、上拉与供电作为缓存依据。网络变化使缓存失效；顺序器件仍逐拍采样。驱动冲突继续以当前时刻记录。参考求解器保留以检查结果一致性。

## 测量证据

`qa/v0.5/performance.json` 记录最终复位边界修复后，同一 Windows 主机、Node v24.19.0、各三次运行的结果。千节点组合链推进 100 μs 的中位数为优化 598.68 ms / 参考 1471.56 ms；CPU+DMA+IRQ 推进 1000 μs 为 624.32 / 1131.99 ms；双 CPU 为 646.37 / 1158.54 ms。三个作品的完整状态与事件均一致。这是测量时的构建和主机结果，不是所有作品或设备的速度保证。

优化没有增加工程预算，也没有省略仿真时间。适合继续扩展的方向包括更细的脏网络调度、Worker 并行与更大的电路预算；本版先保留有实测依据的规模和确定性。
